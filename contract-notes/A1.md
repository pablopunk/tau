# A1 notes

* `[titles]` contract cases stay pending in `packages/core/src/contract.test.ts` (constant `PENDING_A1_TAGS_WAITING_FOR_A2_SETTINGS`). They call `core.settings.setFastModel`, which is A2's stub. Once A2 lands, delete that constant and its spread; the title job already reads `settings.get().fastModel`.
* `projects-api.remove` calls `removeAllOfProject(id)`; threads are tombstoned but the web only gets a `projects` change. For a `conversations` change too, `projects-api.ts` (A2) should `changes.emit({ resource: "conversations", projectId: id })` after `removeAllOfProject`.
* Deleting a project whose thread is still running aborts the run first, so no change is needed in `create-core.ts`.
