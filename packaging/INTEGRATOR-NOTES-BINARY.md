# Integrator notes: release owner

- **`smoke:binary` needs the CLI and core owners' fixes.** On the foundation alone the compiled `tau serve` dies with `lstat '/$bunfs/root/tau'` (CLI item 2) and terminals need the explicit pi-env path (core item 1). With the three `argv[1]` guards and `P5_PI_ENV` patches of the hand-off applied locally (not committed), `pnpm smoke:binary` passed: install.sh, `--version`, health, faux thread, terminal `42marker`, native `claude --version`.
- **SDK import step is skipped locally** with `TAU_SMOKE_SKIP_SDK_IMPORT=1` until core's `sdk-port.ts` change merges; then `tau providers claude-cli refresh` must not say `sdk_missing` and the env var is no longer needed (CI never sets it). After the merge run `pnpm smoke:binary` without it. The CLI/core merges also make the faux thread and terminal steps work without patches.
- **Archive layout assumed by install.sh:** `tau-<version>-<os>-<arch>.tar.gz` holds ONE top-level folder (any name; the workflow uses `tau-<version>-<os>-<arch>`) with `tau`, `pi-env`, `claude-sdk/`, `web/`, `skills/`; install.sh extracts with `--strip-components=1` into `versions/<version>`. The updater (CLI owner) should read `SHA256SUMS` the same way: `<sha256>  <archive>` lines, version parsed from the archive name. `linux-x64-baseline` ships as `linux-x64`.
- **install.sh env** (also for e2e `binary.spec.ts`): `TAU_INSTALL_DIR`, `TAU_BIN_DIR` (link dir, default `~/.local/bin`), `TAU_RELEASE_BASE` (a `file://` or http dir with `SHA256SUMS` and the archive), `TAU_VERSION`, `TAU_INSTALL_NO_START=1`. `scripts/smoke-binary.ts [--release-dir <dir>] [--version v]` builds or reuses a release dir the same way and is reusable as a model for the e2e.
- **`release.yml` deviations:** top-level `permissions: contents: read`, `contents: write` only on the `release` job (the macOS job holds the signing secrets and does not need to write). The "quarantined first run" (P2 criterion) and the systemd swap (P6) steps are `continue-on-error` until the first run shows they behave on hosted runners; remove that flag once they are green.
- **Not done (first CI run):** nothing in `release.yml`, signing, notarization, `ubuntu-24.04-arm`, the systemd script or `fetch-sdk-native.sh` on linux ran. The smaller-entitlement check on `macos-latest` is not scripted (P1 shipped the four). darwin-x64 ships un-smoked.
